## About Me

I am an Electronics & Telecommunication Engineering graduate from **Rajshahi University of Engineering & Technology (RUET)** with a strong interest in **Artificial Intelligence, Machine Learning, Cybersecurity, and Cyber-Physical Systems (CPS)**.

My research focuses on developing intelligent and robust learning systems for security-sensitive and safety-critical environments. I am particularly interested in **cyberattack detection, adversarial machine learning, sensor manipulation detection, autonomous vehicle security, trustworthy AI, and LLM-assisted cybersecurity**.

My current research direction lies at the intersection of:

**AI/ML + Cybersecurity + Cyber-Physical Systems + Autonomous Systems**

I am also interested in applying intelligent systems to emerging areas such as **IoT security, anomaly detection, intelligent healthcare systems, computer vision, and secure AI**.

Alongside research, I have a strong software engineering background that allows me to design and implement complete research prototypes, experiments, APIs, dashboards, and real-world AI applications.

## Research Projects

### RFAT: Deep Learning-Based Detection of Sensor Manipulation Attacks in Autonomous Vehicles

**Domain:** Cyber-Physical Systems • Autonomous Vehicles • AI Security

Developing a deep learning-based framework for detecting **sensor manipulation and false-data injection attacks** in autonomous vehicle environments.

The research includes a MATLAB-based simulation environment and deep learning models for real-time attack detection.

**Research Components:**

* Autonomous vehicle simulation
* Sensor manipulation attacks
* False-data injection
* Time-series data analysis
* Deep learning-based attack detection
* Real-time CPS security

**Technologies:**
MATLAB • Python • Deep Learning • BiLSTM • Transformer-based architectures • Time-Series Analysis

### Defense Against Adversarial Attacks on YOLO-based Object Detection for Autonomous Vehicles

**Domain:** Autonomous Vehicles • Computer Vision • Adversarial Machine Learning

Researching the robustness of YOLO-based object detection systems against adversarial attacks in complex road environments.

The study evaluates attacks such as **FGSM and PGD** and investigates defense strategies for improving object detection resilience.

**Research Components:**

* Adversarial examples
* FGSM and PGD attacks
* Adversarial robustness
* Object detection
* Autonomous vehicle perception
* Defensive machine learning
* Occluded road environments

**Technologies:**
Python • PyTorch • YOLO • OpenCV • Computer Vision • Deep Learning

### Large-Scale Annotated Dataset for Cross-Site Scripting (XSS) Attack Detection

**Domain:** Cybersecurity • Machine Learning • Security Dataset

Curated a large-scale dataset designed for machine learning and deep learning research on **Cross-Site Scripting (XSS) attack detection**.

The dataset contains **1,831,254 records** with textual web payload/query data and binary malicious/benign labels.

**Dataset:**
[![Mendeley Data](https://img.shields.io/badge/Mendeley%20Data-Dataset-blue?style=for-the-badge)](https://data.mendeley.com/datasets/py6cnbgdh2/2)

**DOI:** `10.17632/py6cnbgdh2.2`

**Research Applications:**

* XSS detection
* Malicious payload classification
* Cybersecurity machine learning
* Deep learning benchmarking
* Adversarial pattern analysis
* Web application security

The dataset is also related to the XSS-SafeNet research published in IEEE ICCIT.
